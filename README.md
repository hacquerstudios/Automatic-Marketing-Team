# Automatic Marketing Team

Automatic Marketing Team is an AI-powered social media management platform designed to streamline content creation and preparation for publication.

The project currently supports AI-assisted caption refinement, encrypted credential storage, media importing, and customizable AI prompts.

> ⚠️ Work In Progress (WIP)

---

## Current Features

### Media Handling

- Drag and drop image files
- Drag and drop video files
- Drag and drop text documents
- Automatic file type detection
- Unsupported file validation

### Caption Editor

- Load captions directly from text files
- Rich text editing
- AI-assisted caption refinement
- Custom AI prompts
- Platform-specific prompt customization

### AI Integration

- Google Gemini API support
- Model selection
- AI connection testing
- User-configurable prompts
- Response wait indicators

### Security

- Encrypted settings storage
- Protected API key storage
- Show/Hide credential fields
- Local credential management

### Settings Management

- Persistent settings
- Model selection
- Credential storage
- Configuration testing
